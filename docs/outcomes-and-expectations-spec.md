# מערכת תוצאות, כיסוי התאמות ותיאום ציפיות

## מטרת המערכת

המערכת תמדוד את הדרך המלאה מרכישה ועד תוצאה זוגית, תזהה במהירות חברים שלא קיבלו הזדמנויות מתאימות, ותאפשר להילית לפרסם נתונים וסיפורי הצלחה רק כאשר הם מבוססים ומתועדים. המערכת אינה מודדת רק כמה התאמות נשלחו, אלא גם איכות, תגובה, פגישה, המשכיות וזוגיות.

## מקור האמת הקיים

| שלב | מקור נתונים | כלל חישוב |
|---|---|---|
| הצטרפות למאגר | `singles` | פרופיל אמיתי ששילם ואינו פרופיל seed |
| התאמה נוצרה | `matches.createdAt` | התאמה שנשמרה במערכת |
| התאמה נשלחה | `matches.proposedAt` | נשלחה בפועל לאישור הצדדים |
| מייל נפתח | `emailAOpenedAt` / `emailBOpenedAt` | פתיחה נמדדת בנפרד לכל צד |
| אישור יחיד | `approvedByA` / `approvedByB` | אחד הצדדים אישר |
| אישור הדדי | `matches.status = matched` או שני אישורים | פרטי הקשר נחשפו |
| פרטי קשר נחשפו | `contactRevealedAt` | נקודת מעבר מהתאמה להזדמנות ממשית |
| שיחה / דייט / זוגיות | `matchDetailStatus` | כיום עדכון ידני; יורחב לתיעוד מתוארך ומשוב משני הצדדים |
| חזרה למאגר | `returnedToPoolAt` | ההתאמה הסתיימה והחברים חזרו לקבל התאמות |
| מעקב אוטומטי | `matchWeekFollowupSentAt` / `matchMonthFollowupSentAt` | נשלח מעקב לאחר שבוע ולאחר חודש |

## הגדרות מדדים מחייבות

| מדד | הגדרה |
|---|---|
| חברי מאגר פעילים | פרופילים ששילמו, אינם seed, פעילים ומורשים לקבל התאמות |
| כיסוי התאמות | אחוז החברים הפעילים שקיבלו לפחות התאמה אחת מאז ההצטרפות |
| זמן להתאמה ראשונה | מספר הימים בין `singles.createdAt` לבין ה־`proposedAt` הראשון של אותו חבר |
| ממתינים 14/30 יום | חבר פעיל שלא קיבל התאמה ב־14/30 הימים האחרונים; לחבר שמעולם לא קיבל התאמה נמדד זמן מאז ההצטרפות |
| אישור להצעה | מספר אישורי הצדדים חלקי מספר הצעות ההתאמה שנשלחו לצדדים, ולא מספר אנשים ייחודיים |
| אישור הדדי | מספר התאמות שבהן שני הצדדים אישרו חלקי מספר ההתאמות שנשלחו |
| דייט התקיים | התאמה שקיבלה סטטוס מתועד `met`, עם תאריך דיווח ומקור הדיווח |
| ממשיכים | התאמה שקיבלה סטטוס מתועד `dating` או `talking` לאחר פגישה |
| זוגיות | התאמה שקיבלה סטטוס `together` ואומתה במעקב, ללא חזרה למאגר לאחר מכן |
| פרופיל מלא | כל שדות החובה מלאים, תמונה קיימת ושאלון מדעי הושלם במלואו |

## מדדי כיסוי שיופיעו בדשבורד המאגר

הדשבורד יציג התפלגות של 0, 1, 2 ו־3+ התאמות לכל חבר פעיל; כיסוי ב־30/60/90 יום ממועד ההצטרפות; חציון וממוצע ימים להתאמה ראשונה; רשימת ממתינים מעל 14 ו־30 יום; ופערי היצע לפי מגדר, קבוצת גיל, אזור ורמת דתיות. בנוסף יוצגו יחס נשים־גברים, אחוז פרופילים מלאים, אחוז בעלי תמונה ואחוז משלימי שאלון מדעי.

## מניעת נתונים מטעים

מדד “אחוז הצלחה” לא יחושב עוד כיחס בין אנשים ייחודיים בשלבים שונים. כל יחס יחושב על אותה יחידת מדידה: הצעות, התאמות או חברים. תוצאת “זוגיות” לא תוסק מעצם אישור הדדי. אישור הדדי הוא חשיפת פרטים בלבד; זוגיות דורשת דיווח מתועד ואימות מעקב.

## תיאום ציפיות לגבי 299 ש״ח

> התשלום הוא עבור הצטרפות למאגר, בניית פרופיל והשתתפות בתהליך התאמה מקצועי. הוא אינו רכישה של שירות אישי צמוד ואינו התחייבות למספר התאמות או לתדירות קבועה. התאמה נשלחת כאשר נמצאת התאמה הדדית ורלוונטית, לאחר בדיקת הנתונים של שני הצדדים.

המסר יופיע לפני התשלום, באישור ההצטרפות, באזור האישי, במסע 90 הימים, בשאלות הנפוצות ובתשובות השירות. לצד ההבהרה יוצג הערך: מאגר פעיל, איזון מגדרי הנמדד בזמן אמת, פרופילים מפורטים, תמונות, שאלון מדעי, התאמה הדדית ובקרה אנושית.

## כללי שימוש בנתונים בפרסום

נתוני איזון, השלמת פרופילים, כיסוי וזוגיות יופיעו בפרסום רק מתוך שאילתה מתועדת ובציון תקופה. סיפור אישי, ציטוט, שם או תמונה יפורסמו רק לאחר הסכמה מפורשת ומתועדת של הלקוח/ה. לא יוצגו עדויות מומצאות, שמות בדויים המוצגים כלקוחות אמיתיים או הבטחה לתוצאה אישית.

## סדר המימוש

תחילה יתוקן דשבורד המאגר ויוצגו מדדי הכיסוי האמיתיים. לאחר מכן יורחב סטטוס ההתאמה לדייט, המשכיות וזוגיות עם תאריכים ומקור דיווח. בשלב הבא ייבנו טפסי משוב והסכמה לפרסום, מסע 90 יום ואפסייל התנהגותי. רק לאחר הצטברות נתונים מאומתים תופעל ספריית מסרים לפרסום.
