# מפרט Database Plus

## הצעה מסחרית מאושרת

Database Plus הוא שירות אופציונלי לחברים פעילים במאגר. דמי ההצטרפות למאגר נשארים 299 ש״ח חד־פעמיים; Plus עולה 99 ש״ח לחודש בנוסף, וניתן לבטל בכל עת. ביטול Plus אינו מבטל את החברות הרגילה במאגר.

| רכיב | התחייבות השירות |
|---|---|
| הצעות התאמה | לפחות שתי הצעות התאמה חדשות שנבדקו ונשלחו בכל מחזור חיוב אישי |
| בדיקה אנושית | קדימות באיתור ובבדיקה ידנית של מועמדים מתאימים |
| הרחבת חיפוש | הרחבה חכמה של טווחים רק באישור החבר/ה וללא חציית תנאי סף מהותיים |
| שירות | ערוץ שירות לקוחות Plus בעדיפות דרך המספר העסקי, לא שירות אישי של הילית ולא מענה 24/7 |
| חשיפה בסושיאל | אפשרות בלבד, לאחר הסכמה מפורשת ונפרדת לטקסט ולתמונה; ללא פרטי קשר פומביים |

הבטחת שתי ההתאמות היא הבטחה לשתי **הצעות שנשלחו בפועל**. היא אינה הבטחה לאישור הדדי, לדייט או לזוגיות. שליחה חוזרת של אותה התאמה אינה נספרת פעמיים, והצעה שסותרת תנאי סף מהותיים אינה נשלחת רק כדי להשלים מכסה.

## מחזור החיוב והמעקב

כל מנוי נמדד לפי מחזור חיוב אישי. לדוגמה, מנוי שהופעל ב־12 בחודש נמדד עד ה־11 בחודש הבא. התאמה נספרת למחזור כאשר `proposedAt` נמצא בתוך טווח המחזור והיא כוללת את חבר/ת Plus כאחד הצדדים.

| מצב | סימון |
|---|---|
| 0/2 בתחילת המחזור | ניטרלי |
| 1/2 | צהוב |
| 2/2 | ירוק — היעד הושלם |
| פחות מ־2 בשבעת הימים האחרונים למחזור | אדום + משימת צוות אוטומטית |

## תצוגה ב־CRM

תג `PLUS` יופיע בכל כרטיס אדם ובכותרת הפרופיל. טאב ייעודי יציג חברים פעילים, ממתינים, תשלום שנכשל, בוטלו והסתיימו. לכל חבר יוצגו תאריך התחלה, תחילת וסיום המחזור, תאריך חיוב הבא, סטטוס תשלום, מונה 0/2–2/2, הסכמה לסושיאל, סטטוס שירות ואחראי/ת.

## חיוב Grow

Grow תומכת בחיוב חודשי מתחדש באמצעות `CreatePaymentProcess` עם `pageCode` ייעודי שהוגדר להרשאה מסוג Premium Recurring Payment. לפי התיעוד הרשמי, השירות דורש הרשאה מחשבון Grow והסכום החודשי נשלח בפרמטר `sum`. מספר הריצות נשלח ב־`paymentNum`; לצורך ביטול בכל עת יש להגדיר את המוצר בממשק Grow כמנוי מתחדש שניתן לעצירה, ולא כעסקת תשלומים רגילה.

הקוד יוכן עבור משתנה סביבה `GROW_PAGE_CODE_PLUS`, אך כפתור התשלום לא יופעל בפרודקשן עד ש־Grow יספקו pageCode ייעודי ויאשרו שהוראת הקבע מאפשרת עצירה/סגירה דרך API או ממשק הניהול.

### מקורות Grow רשמיים

| מקור | פרט שנאמת |
|---|---|
| [Premium Recurring Payment](https://grow-il.readme.io/reference/premium-recurring-payment) | נדרשת הרשאה לשירות; חיוב מנוהל דרך `CreatePaymentProcess` עם `pageCode` ייעודי; `sum` הוא סכום החיוב החודשי ו־`paymentNum` מגדיר את מספר הריצות |
| [Grow API למפתחים](https://grow.business/api-developers/) | Grow מציינת תמיכה בהוראות קבע, שליטה בתאריך ובמחיר, והשהיה, עצירה או סגירה של החיוב |
| [Create Payment Process](https://developers.grow.business/reference/create-payment-process-9) | קריאות יצירת התשלום צריכות לצאת מהשרת בלבד |

## מדיניות השקה

הפיילוט לא ייפתח ולא תישלח פנייה ללקוחות עד להצגת מסכי המכירה, התשלום, ההסכמה לסושיאל וטאב הניהול ואישור מפורש של הילית.
