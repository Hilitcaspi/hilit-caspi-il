# מסלול כניסה לאזור האישי

המסלול המומלץ הוא **כניסה ללא סיסמה**. חברי המאגר מזינים את כתובת המייל הרשומה ומקבלים קישור אישי. כך אין צורך לזכור סיסמה נוספת, והאזור האישי נשאר נקודת הכניסה להתאמות, Boost, עדכון פרופיל ותוצאות השאלונים.

| נקודת מגע | יישום |
|---|---|
| דף הבית בדסקטופ | כפתור קבוע „האזור האישי” בניווט העליון |
| דף הבית במובייל | „כניסה לאזור האישי” בתוך התפריט |
| תחתית דף הבית | קישור נוסף תחת „קישורים מהירים” |
| מייל אישור הדדי | כפתור „כניסה לאזור האישי” עם הקישור של הנמען בלבד |

מסך הכניסה נבדק בדסקטופ ובמובייל ונשאר קריא ונגיש. כדי לא לחשוף אם כתובת מסוימת קיימת במאגר, המסך מציג תשובה אחידה לכל בקשה. השרת שולח קישור רק לחבר מאגר פעיל ובתשלום, משתמש בדומיין הרשמי בלבד, מגביל שליחות חוזרות לחמש דקות ומייצר טוקן אישי אם חסר טוקן קיים.

במייל שלאחר אישור הדדי נשמרת הפרדה ברורה בין קישור התגובה להצעה לבין הכניסה לחשבון. כל צד מקבל קישור שנבנה מהמייל ומהטוקן שלו, ולא מהפרטים של הצד השני. במייל Boost הכותרת מציינת שההתאמה אושרה, והכפתור מוביל ישירות לטאב ההתאמות באזור האישי.
