## 6. טקסטים למודעות

הקובץ `ad_copybook_he.md` הוא מקור האמת לטקסטים. הוא כולל Primary Text, Headline, Description ו־CTA לכל אחת מזוויות הקמפיין: פעולה לשנה החדשה, ערך הבאנדל, שקיפות ונתונים, כמות מול דיוק, רימרקטינג, Instagram Boost, WhatsApp וניוזלטר.

אין להוסיף לטקסט ״מגיעים בזוג לחג״, ״התאמה מובטחת״, ״לפחות X התאמות״, טיימר אישי או ספירת זוגות שאינה נשלפת ממקור מאומת.

## 7. מדידה ואירועים

עמוד הבאנדל שולח `ViewContent`, `InitiateCheckout` ו־`Purchase`. רכישה נשלחת מ־Grow webhook ל־Meta CAPI ול־GA4 עם `event_id` משותף לצורך Dedup. ליד התשלום שומר `utm_source`, `utm_medium`, `utm_campaign`, `utm_content`, `utm_term`, `metaCampaignId`, `metaAdSetId` ו־`metaAdId`. `placement` ו־`site_source_name` נשמרים בתוך `utm_term` לצד שם ה־Ad Set כדי לשמור תאימות למסד הפעיל.

לפני פתיחת תקציב יש לבצע רכישת בדיקה מאושרת ולוודא שרשומה אחת בלבד מופיעה ב־Grow, CRM, GA4 ו־Meta Events Manager. אין לבצע רכישה אמיתית או חיוב ללא אישור הילית.
