# בדיקת תיאום ציפיות — דסקטופ ומובייל

נבדקו דף המאגר, טופס ההרשמה ודף התודה ברוחב דסקטופ 1280px וברוחב מובייל 390px.

בדף המאגר רכיב ההבהרה מופיע לאחר הסבר התהליך, לפני הצגת הרכב המאגר. הוא מציג באופן קריא את ההבחנה בין דמי הצטרפות לבין ליווי אישי, וכן נתוני נשים/גברים, שאלון מדעי ופרופיל מלא מתוך הנתונים החיים.

בטופס ההרשמה נבדק שהמבנה הקיים נשמר בדסקטופ ובמובייל. רכיב ההבהרה יוצג בשלב התשלום, ולכן אינו מופיע במסך הפרטים הראשוני שנלכד בצילום.

בדף התודה ההבהרה מופיעה מיד לאחר אישור התשלום ולפני הקריאה להשלמת השאלון. הטקסט קריא, אינו דוחק את כפתור הפעולה, ואין גלישה אופקית במובייל.

לא נמצאו חפיפות, טקסט בלתי קריא או שבירת פריסה בשלושת הדפים שנבדקו.
