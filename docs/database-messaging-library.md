# ספריית מסרים למאגר הרווקים

**בעלת המסמך:** הילית כספי  
**מטרה:** לייצר שפה עקבית בקמפיינים, סושיאל, ניוזלטרים, מיילים ושירות לקוחות, תוך שימוש בנתוני מערכת מאומתים בלבד.

> ההצטרפות למאגר היא כניסה למערכת התאמה מקצועית. היא אינה רכישה של הילית, שירות אישי צמוד, מכסת התאמות או התחייבות להצעה בכל כמה ימים.

| עיקרון | ניסוח מאושר | ניסוח שאסור להשתמש בו |
|---|---|---|
| כמות | "המטרה היא להגדיל את מספר ההזדמנויות המתאימות" | "תקבלו הרבה התאמות" |
| תדירות | "הצעה נשלחת כאשר נמצאת התאמה הדדית שעברה בדיקה" | "התאמה חדשה בכל שבוע" |
| איכות | "פרופילים מפורטים, שאלון מדעי ובדיקה מקצועית" | "כל האנשים במאגר איכותיים" |
| איזון | "נכון לתאריך המדידה, החלוקה היא X% נשים ו-Y% גברים" | "המאגר מאוזן תמיד" |
| תוצאה | "סיפור אומת ופורסם בהסכמה" | סיפור, שם או ציטוט ללא תיעוד הסכמה |

ה־CRM כולל ספרייה חיה שמחליפה את המשתנים במספרים הנוכחיים ומציינת את תאריך המדידה. בכל פרסום של נתוני מערכת יש להשתמש בטקסט שהופק באותו יום. סיפורי הצלחה ותמונות יפורסמו רק לאחר אימות מנהלי והסכמה מפורשת ברמת החשיפה המבוקשת.

## תשובה לטענה "קיבלתי רק התאמה אחת"

היי, אני מבינה את הציפייה לקבל עוד הצעות. ההצטרפות למאגר היא כניסה למערכת התאמה מקצועית, ולא רכישה של מכסת התאמות או שירות אישי צמוד. אנחנו לא שולחים אדם רק כדי לייצר כמות. הצעה נשלחת כאשר יש התאמה הדדית ורלוונטית שעברה בדיקה. המטרה שלנו היא להגדיל כל הזמן את מספר ההזדמנויות המתאימות במאגר, תוך שמירה על האיכות ועל הפרטיות של שני הצדדים. הנתונים משתנים לפי גיל, אזור, אורח חיים והעדפות.

## הנחיית שימוש

המסר אינו נועד להתגונן או להאשים את הלקוח בחוסר סבלנות. הוא צריך להכיר בציפייה, להסביר את המודל, להציג את מטרת העל ולהציע בדיקת פרופיל והעדפות במקרה של המתנה ארוכה.
